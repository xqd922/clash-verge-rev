# upstream-v2.5.5 个性化改动

基准是官方稳定版 `v2.5.5`。定制都在分支 `upstream-v2.5.5` 上，没有改 `main`。当前版本是 `2.5.5-3`。

## 2.5.5-1：藏掉不用的入口

- 侧边栏去掉首页。访问 `/` 会直接进入代理页。
- 启动页如果还是旧的 `/home` 或 `/`，启动时会改成 `/proxies`。设置里的默认启动页也是 `/proxies`。
- 订阅页底部的全局扩展（Merge）和脚本覆写（Script）两张卡片去掉，中间的分隔线一并去掉。
- 取消首页预加载。首页和这两张卡片的代码还在仓库里，只是界面不再引用。

## 发版方式

- 发布标签必须来自 `upstream-v2.5.5`，不再要求来自 `main`。
- macOS 的 Apple 签名密钥如果没有配置，就跳过，避免空密钥中断构建。

## 2.5.5-2：标题栏和代理图标

- Windows 标题栏改成系统原生按钮：宽 46px、无圆角、使用 Segoe Fluent 字形。关闭按钮悬停为系统红 `#C42B1C`，按下时变淡。
- 标题栏高度改为 34px，并去掉内边距。更新红点上移，避免挡住左侧文字。
- 代理组的筛选图标从搜索样式改成漏斗（FilterAlt）。

## 2.5.5-3：对齐 personal 的四处界面

- 延迟测试、定位、筛选、排序按钮放在每个代理组标题的左侧，不再单独占列表上方一行。
- Windows 冷启动固定使用自定义标题栏：不恢复历史窗口装饰状态，首帧就按「非 macOS 即无边框」渲染，避免内容先下移再弹回来。macOS 仍使用系统标题栏。
- 代理组的展开状态在首帧就从本地记录读出，减少打开时的抖动。
- 连接表中的下载、上传、下载速度、上传速度、时长，第一次点击按从大到小排序。表头不换行；速度列加宽到 82px，流量列加宽到 80px。
- 订阅卡片按宽度分列：窄屏 1 列、小屏 2 列、中屏 3 列、宽屏 4 列。不再使用「最小 260px 自动填充」，常见窗口宽度会重新出现一排三个。

## 检查配置

`knip` 忽略已隐藏的首页、订阅扩展模块，以及因此变成未引用的导出，避免把这些误报成无用代码。
